# Eingaben dieses Laufs

Hier exakte Kopien der tatsächlich hochgeladenen Forschungsdateien und den verwendeten Prompt ablegen. Nicht pauschal die jeweils neueste Recherche kopieren: Maßgeblich ist der Eingabestand beim Start des Laufs.

Dateiname, Quelle der Kopie und SHA-256-Prüfsumme in `input-manifest.json` dokumentieren. Bei einem aus dem Chat rekonstruierten Prompt diesen Herkunftshinweis erhalten, bis ein Serverexport den Text bestätigt.
